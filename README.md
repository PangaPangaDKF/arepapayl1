# ArepaPay v2

Payments and banking for Venezuela on a permissioned Avalanche L1 (testnet): KYC-gated accounts, encrypted balances, merchant
payments with amounts in bolívares, cash ↔ USDT through merchants, and a bank-style back office.

**Status: Phase 1 (rails). Testnet only. No real money. Nothing is deployed yet.**
